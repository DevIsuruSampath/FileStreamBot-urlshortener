# FileStreamBot-urlshortener

URL shortener service for FileStreamBot.

## Branching Strategy

- `main` → Stable production code
- `dev` → Main development branch (current working branch)
- `feature/*` → Developing new features
- `bugfix/*` → Fixing bugs found in `dev`
- `release/*` → Preparing a new version
- `hotfix/*` → Emergency fixes for production

## Quick Start

```bash
git clone git@github.com:DevIsuruSampath/FileStreamBot-urlshortener.git
cd FileStreamBot-urlshortener
git checkout dev
```

## Notes

This repo is initialized with `main` as the default branch.
